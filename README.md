# 🚖 Rapido-Inspired Responsive Website

A responsive **ride-hailing website** inspired by Rapido, built using **HTML5, CSS3, and Bootstrap 5**. This project focuses on creating a clean, responsive, and user-friendly interface for a modern ride-booking platform.

## 🌐 Project Overview

The website includes a navigation bar, hero section, ride services, feature cards, Captain earning section, and app download section.

The project helped me practice **Bootstrap's grid system, responsive design, cards, navigation components, and webpage layouts**.

## ✨ Features

* 🏠 Responsive navigation bar
* 🚕 Ride-booking hero section
* 🛵 Multiple ride services
* 💰 Best fare section
* ⚡ Quick pickup feature
* 📍 Never Too Far service
* 👨‍✈️ Earn with Rapido section
* 📱 Download app section
* 📐 Responsive layout for different screen sizes
* 🎨 Bootstrap-based UI design

## 🛠️ Technologies Used

# 🛒 Mini Shopping Cart

A simple and interactive **Mini Shopping Cart** built using **HTML, CSS, and JavaScript**. This project demonstrates how JavaScript can be used to dynamically add products to a cart, update the cart item count, and calculate the total price.

## 📌 Project Overview

This project contains a simple shopping interface with different products such as **Nike Shoes, Smart Watch, and Headphones**.

Users can click the **Add to Cart** button to:

* Add products to the cart
* Increase the cart item count
* Display selected product details
* Automatically calculate the total price

## ✨ Features

* 🛍️ Product cards with images
* ➕ Add to Cart functionality
* 🔢 Dynamic cart item count
* 💰 Automatic total price calculation
* 📋 Displays cart details dynamically
* 🎨 Clean and simple user interface
* 📱 Responsive product layout

## 🛠️ Technologies Used
